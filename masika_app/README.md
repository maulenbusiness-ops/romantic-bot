# Masika

Masika is a simple mobile expense tracker for monitoring spending by category, setting budgets, and viewing daily, weekly, and monthly totals.

## Features
- Add expenses with amount, category, date, and note
- View total spending for a selected period
- See category breakdowns with charts
- Track category budgets and over-limit warnings
- Browse recent expenses and search by filters

## Run locally
1. Install Flutter SDK.
2. Open the project folder:
   `cd masika_app`
3. Fetch dependencies:
   `flutter pub get`
4. Start the app:
   `flutter run`

## Stack
- Flutter + Dart
- Material 3 UI
- fl_chart for summaries
- Hive / Isar can be added later for persistent storage
